WeCanFindIntern for macOS — 首次打开说明

此版本使用无证书的 ad-hoc 完整性签名，没有经过 Apple 公证。
macOS 首次打开时需要由用户手动信任：

1. 将 WeCanFindIntern.app 拖到“应用程序”文件夹。
2. 尝试打开一次，然后关闭 macOS 的安全提示。
3. 打开“系统设置”>“隐私与安全性”。
4. 在“安全性”区域找到 WeCanFindIntern，点击“仍要打开”。
5. 输入 Mac 登录密码并确认。以后可以正常双击打开。

安装前请在 GitHub Release 的 SHA256SUMS.txt 中核对下载文件。
请勿全局关闭 Gatekeeper，也不要安装来源不明的副本。
