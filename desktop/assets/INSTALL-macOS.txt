WeCanFindIntern for macOS — First Launch Guide

This release uses a certificate-free ad-hoc integrity signature and is not
notarized by Apple. The first launch requires manual approval in macOS:

1. Drag WeCanFindIntern.app into the Applications folder.
2. Try to open it once, then dismiss the macOS security warning.
3. Open System Settings > Privacy & Security.
4. In the Security section, find WeCanFindIntern and click Open Anyway.
5. Enter your Mac login password and confirm. You can open the app normally
   afterward.

Before installing, verify the download against SHA256SUMS.txt in the GitHub
Release. Do not disable Gatekeeper globally or install copies from unknown
sources.
